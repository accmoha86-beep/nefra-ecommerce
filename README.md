# NEFRA — Everything. Elevated. 👑

Premium multi-country, multi-language e-commerce platform.

## Features
- 🌍 5 Countries: Saudi Arabia, UAE, Qatar, Egypt, Italy
- 🗣️ 3 Languages: Arabic (RTL), English, Italian  
- 🎨 5 Premium Themes: Elegant Dark, Modern Soft, Royal Premium, Pure Minimalist, Natural Organic
- 💳 Dynamic Payment Gateways per country
- 🧾 Electronic Invoicing (ETA, SDI, PDF)
- 📊 Admin Dashboard with No-Code Command Center
- 📱 Full Mobile Responsive design

## Tech Stack
- React 18 + TypeScript + Vite
- Express.js (production server)
- Deployed on Railway

## Run Locally
```bash
npm install
npm run dev
```
